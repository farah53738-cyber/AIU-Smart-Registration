# AIU Smart Course Registration System

**D7 – Final Release 2.0**

Course: CSC 340 – Software Engineering

## Project Overview

Our system allows students to browse courses, register for classes, manage their schedules and submit requests. It also provides separate dashboards for advisors, instructors, registrars and administrators.

## Release 2.0

For D7, our instructor assigned a change request to introduce exact request-number lookup on the advisor dashboard. This allows advisors to find and review specific student requests more easily.

We implemented the change, updated the system documentation and conducted regression testing.

## Technologies

- Java 23
- Spring Boot
- MySQL 8
- HTML, CSS and JavaScript
- Maven

## Installation

1. Import the database using MySQL Workbench.
2. Configure the database connection in application.properties.
3. Run the Spring Boot application.
4. Open http://localhost:8082.
